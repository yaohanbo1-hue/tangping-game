# v2.1.0 守夜互动与宿舍发现

本轮承接2026-11-10的新要求：让备战有取舍、环境能探索、室友对战况有回应，增加多个彩蛋。三位子代理分别实现玩法、发现系统和界面，根代理负责接入、交叉审查、存档与实际战役验证。按维护者要求直接合并推送，不创建PR；推送后核对CI与线上游戏。

## 怎么进入

完成第2波后，桌面右侧显示“守夜手记”；手机从“管理→守夜手记·宿舍角落”进入。手记不强制弹出，打开时暂停战斗，合上恢复原来的运行或手动暂停状态。剧情可以接管手记，关剧情后恢复正确的原状态。

“这一夜”列出可选备战安排与真实代价；“宿舍角落”可观察五件物品；“发现册”记录六件发现，未发现只显示线索，不直接给解法或主线答案。

## 守夜抉择

完成第2／6／10／14／18／22波后依次提供以下六种情境，并每四轮轮换至第55波前。每个机会最多接受一次，也可不介入；不接受时原有战斗、资源与随机序列保持不变。

| 情境 | 可做的取舍 |
|---|---|
| 门缝里的螺丝 | 花金币修补最危险的完整铁门，或花电力小修现存建筑 |
| 插座正在发烫 | 下一波开场短时超频，或付费校准尚未就绪的冻结开关 |
| 拐角又响了三声 | 多守3只普通梦魇、清波后取回物资，或花物资封住下一波召唤 |
| 借来的工具箱 | 押金约定下一波不新建、清波结算，或不接约定直接换电力 |
| 走廊路口的信号灯 | 将前排普通队列集中到最完整一路，或分散三路；不改变总敌人数和Boss |
| 值夜人的补给单 | 一次性金币／电力互换，为当前升级计划调整资源 |

收益、成本、禁用原因及结算条件读取实际数据。无固定计量目标的安排显示“等待本波结束结算”，不把秒数伪装成任务完成百分比。室友短句对应真实破门、床铺危险、Boss打断与已完成安排，去重并限制历史长度。

## 六个发现

雨窗、床头灯、停下的钟、折纸猫和门边刻痕都有可观察细节。发现依赖环境之间的呼应、跨波回访、实际危险后的修复、真实Boss战和防线颜色；不按一次按钮就发大量资源，也不要求输入作弊码。

发现只解锁收藏与短回应，不增加金币、电力、灵魂或战斗加成。收藏跨局保留，可随存档JSON导出／导入；旧档不会清掉已有新收藏，未完成的交互顺序不靠读档重放。

## 接入与修复

- `night-watch.js`只管理显式接受的局内安排，`hidden-secrets.js`管理观察与收藏；`watch-ui.js`／CSS提供原生布局与五个原创SVG道具形象。
- 新局、备战／波次切换、模拟时钟及存读档均已挂接；界面更新节流，保留焦点，输入不会穿透手记去放技能或建造。
- 技能冷却加入v7存档并按真实技能上限校验，旧档缺失字段默认就绪；修复原先读档重置技能的问题。
- 冻结校准已应用标记持久保存，重开本波不再重复退款；押金违约在暂停后立即保存也会记录，读档不能洗掉新建行为。
- 修正室友对象误显示、非计量任务的虚假进度、禁用原因与下一张卡重叠，以及小屏点击道具看不到回应的问题。

## 自检范围

- 新玩法78项、发现29项、根接入20项，接入完整逻辑回归；合计3821项具名检查，另有构建、许可与本地服务器检查。
- 根接入检查使用两种种子的实际20秒战斗，逐秒比较默认不选与禁用新模块的战斗轨迹和随机值；不是只检查静态字段。
- 普通／困难各一条实际费用、正常起始经济、完整60波的守夜选择路线，记录实际接受的安排；原始结果为`artifacts/watch-campaigns.json`。程序操作不代替人工难度评价。
- 守夜界面实际浏览器检查桌面、320px大字、横屏与Linux WebKit；本机Windows WebKit出现启动环境失败，未把未执行的页面检查记为通过。最终结果以推送提交的Linux CI为准。
- 原有物理Android、iPhone、外放／耳机、完整剧情与人工难度五项仍等待真实记录，没有用浏览器仿真抵扣。

实际截图和运行结果由`tests/watch-ui.browser.test.js`输出到`artifacts/watch-ui/`；CI保存该目录与守夜战役JSON，源码中的具名测试可复现。

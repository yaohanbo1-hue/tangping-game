# 敌人与词缀反制验收

`node tests/enemy-counterplay.test.js` 生成。35个普通敌种中包含基础敌人、被动特性与主动技能，并非35套主动施法。运行时行为另由 `enemies.test.js`、`enemy-abilities.test.js` 和 `boss-encounters.test.js` 验证。以下说明也用于实际游戏的图鉴与波次预告。

## 5位Boss

| Boss／行动 | 前摇／冷却（模拟秒） | 应对 |
|---|---:|---|
| 梦魇领主／号令冲锋 | 1.8／8 | 冻结或眩晕打断号令；分路防守召来的护卫。 |
| 深渊巨口／深渊汲取 | 2.2／9 | 标记锁定后冻结／眩晕巨口，或出售诱饵；减伤会压低汲取量，护盾承接生命损失。 |
| 机械核心／轨道扫射 | 2／10 | 冻结或眩晕打断；用护盾与抢修承接扫射，趁核心过热集火。 |
| 虚空之影／虚空跃迁 | 1.9／8.5 | 跃迁前控制它；完整铁门挡住落点，利用施法与落地显形期集火。 |
| 终焉梦魇／三声终钟 | 1.4／10 | 依次预警三路；控制可打断整轮，保持铁门完整并保留抢修。 |

阶段会打断旧施法并提供对应防守收益；武器连续眩晕触发4秒韧性，主动时间冻结仍可打断。读档依旧重开当前波、清空敌人临时施法；当前波阶段奖励账本保留，避免重新获得。前摇、死亡、阶段、目标出售、召唤上限与账本另有专项逻辑及触控测试。

## 10种普通精英词缀

| 词缀 | 效果 | 应对 |
|---|---|---|
| 坚韧 | 生命 x3 | 集中火力并搭配易伤／破抗，避免伤害分散。 |
| 迅捷 | 速度 +80% | 提前布置减速与拦截，留意冲线时间。 |
| 护盾 | 带可再生护盾 | 持续接触压住回盾，或用毒液绕盾。 |
| 抗性 | 全属性减伤 40% | 优先破抗科技、腐蚀与易伤，再集中输出。 |
| 吸血 | 攻击回复生命 | 减伤、控制并守住门线，减少实际攻击带来的回血。 |
| 狂暴 | 残血时狂暴 | 在残血前保留控制与爆发，避免让狂暴敌人贴脸。 |
| 分裂 | 死亡后分裂 | 预留群攻与射程处理两只分裂体；召唤封印可拦截分裂。 |
| 亡语 | 死亡时爆炸 | 保持距离击杀，提前修复爆炸半径内的防御。 |
| 再生 | 持续回复生命 | 集中爆发压过回血；控制主要延缓推进，再生仍会持续。 |
| 重甲 | 受到伤害固定减免 | 提高单发伤害或配合破甲；持续伤害按时间结算固定减伤。 |

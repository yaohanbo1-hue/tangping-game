## 验收原则

- 已有测试通过仅证明其覆盖行为；不能据此认定平衡、音质或实机性能达标。
- 性能使用同一场景、实体、浏览器与设置比较，同时记录模拟、绘制、界面和帧间隔。仿真结果明确标记，不冒充物理设备。
- 平衡使用合法经济和操作路线，不注入资源证明通关；记录失败路线、失误成本、Boss 存活时间与反制窗口。
- 剧情验收覆盖所有玩家可见入口；已领取奖励与已揭示剧情分别记录。
- 所有必需项验收后才能把总目标标为完成；设备验收待实际设备操作及结果回传。

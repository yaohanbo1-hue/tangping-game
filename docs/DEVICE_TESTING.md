# Android／iPhone 真机验收入口

本地准备和浏览器仿真已经完成；截至2026-11-08，没有物理Android或iPhone的实际操作结果。本页提供可执行入口，不把仿真改名为真机测试。

## 打开方式

电脑在仓库目录依次运行：

```powershell
npm run build
npm run device:lab -- --lan
```

终端会显示当前电脑的局域网地址。手机与电脑连接同一Wi-Fi后，在手机浏览器打开终端打印的 `http://电脑地址:4173/`，再点“打开游戏”。电脑本机可用 `http://127.0.0.1:4173/`。端口占用时添加 `--port=4174`；只供本机使用时省略 `--lan`。无法连接时检查同一网络与本机端口访问设置。Ctrl+C停止服务。

这里使用独立端口，浏览器存储与正式在线站点分开；需要现有进度时，从游戏存档面板手动导入已导出的JSON。本工具共享游戏HTML、`assets/`游戏资源、`audio/`音乐、独立试听代码及验收页，报告写在电脑的 `artifacts/device-reports/`，不会上传GitHub或其他服务器。音乐与视频支持单段HTTP字节请求，返回206及Content-Range，便于浏览器加载与定位媒体。

## 检查范围

验收页逐项记录：竖屏、横屏、旋转、安全区、大字、建造与技能、符文、剧情、存读档、全屏、后台恢复、声音及密集战斗。每项默认“未测试”，可选“通过／有问题”，并记录复现步骤。

- Android：建议使用常用浏览器完成一轮，在同一局旋转后点按原位置，检查系统手势区和地址栏伸缩。
- iPhone：使用Safari检查首次手势解锁声音、剧情压低音乐及恢复；全屏不可用时检查横屏／旋转回退。Windows WebKit仿真缺少Web Audio，不能替代此项。
- 每台设备填写型号、系统和浏览器版本；只有亲自在物理手机操作后勾选“我正在物理手机上操作”。工具不会根据User-Agent自动认定真机。

## 性能采样

先在游戏中实际进入待测战斗，回验收页点“采样当前战斗10秒”，立即切到游戏并保持前台。它临时计时原有模拟和绘制函数，结束后恢复；不注入金币、建筑、敌人或管理员能力。

报告包含视口／visualViewport、安全区、音频解锁状态、全屏能力、画质、波次、实体数以及帧间隔／模拟／绘制的平均、P95和最大值。暂停状态和样本数量会明确标出；后台、空场或暂停时的结果不能当作密集实战性能。

点击“保存到本地报告”后可下载JSON副本。文件保留 `physicalConfirmed`、各检查结果与备注；所有自动测试生成的样例均为 `physicalConfirmed:false`，不计入实机验收。

## 16种声音逐项试听

展开“16种声音试听与听感记录”，填写外放／耳机型号，再逐项播放11种武器和五Boss预警。试听使用实际游戏的表现随机源与音效模块，沿用默认战斗／界面分组音量，另有独立主音量；不读取或改写游戏的音量偏好与存档。

每项听感默认为“未测试”，由测试者选择“清楚可辨／容易混淆／听不清／刺耳”。点播放不会自动记成通过。单项试听后仍需进入真实战斗检查混音；切到游戏或后台时，验收页停止声音并挂起自己的音频上下文。

浏览器不提供或无法启动Web Audio时，工具尝试播放 `artifacts/audio/chromium-weapon-sampler.wav` 中相应的1秒录音，并按默认分组音量补偿。报告明确写为 `recorded-pcm`，不能当作Web Audio手势解锁通过。若录音尚未生成，可先在电脑运行 `npm run test:audio`；播放失败时仍保留未测试状态。

报告格式为schema 2，新增16项 `listening`、输出设备 `listeningSetup`，以及试听方式／上下文状态／音量 `audioPreview`。物理设备确认继续要求测试者实际操作并明确填写，不根据浏览器名称自动判定。

五幕剧情另需完整观看和聆听；本地15组画面与媒体检查见 [STORY_PRESENTATION_REVIEW.md](STORY_PRESENTATION_REVIEW.md)，不抵扣真人情绪评价。

## 已验证的工具行为

`npm test`验证共享路径范围、真实MP3／MP4字节读取、报告字段、数值边界和手动确认规则。`npm run test:lab`在真实Chromium页面播放生产音效、检查试听不改存储、逐项听感保持手动、完成10秒游戏采样，确认计时函数恢复／资源未被注入；另模拟缺少Web Audio，检查PCM回退与320px布局。保存的样例明确为非物理设备。这里只证明工具可用；Android和iPhone的实际记录仍待回传。

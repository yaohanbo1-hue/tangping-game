# 敌人生命结算

spawnEnemy 收集梦境、试炼与最终精英词缀后，仅调用 EnemyBalance.health 一次。本体、生命条上限、盾量、阶段盾分段均来自同一次结果，不在后续路径补乘 HP。

基线 v1.9.2 基础成长公式保留；2.0 曲线以三次 Hermite 插值连接以下锚点。1—10 波完全相同，锚点间无跳变，60 波后继续线性增长。第 11 波为了平滑过渡从 1.0 逐步抬升，非瞬间跳到 1.1。

盾卫的本体和盾都按最终生命同步增长。精英生命因子只乘一次；多个盾来源取最大比例，避免重复堆盾。快速单位速度未改。困难与地狱、梦境、试炼因子保持原有语义。无限普通队列与 Boss 数量均封顶，HP 最高有限值 1e150，波次输入限 9999。

25 波开始固定三路先头小队（前排、支援、快攻），其余保留原有随机池与总数。治疗/干扰/织梦/死灵仍可通过目标优先级与元素组合反制。这部分仅完成基础配置，Boss 技能差异化、经济模拟与玩家实际通关验证仍待进行。


`node tests/simulate.js` 使用固定种子与公开预算，在实际 step/开火/伤害/敌人 AI 内比较三种阵容于 10、20、30、40、50、55、60、120、500 波的表现。记录实际击杀时间、有效 DPS、每路破门率、Boss 存活/战斗时间及收入。旧模型只替换 HP 曲线为 1，其他条件相同。每场上限 180 秒；未击败 Boss 记为未完成，不伪填时长。JSON 原始数据由 Actions 上传。该实验是受控的单波场景，不证明完整经济运营或玩家可通关。

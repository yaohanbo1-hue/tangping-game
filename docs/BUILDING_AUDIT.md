| 导弹溅射以飞行上一步位置测距 | 改在实际目标处结算；一秒大步飞行测试确认目标附近敌人中弹 |
| 高等级冰霜减速超过 100%，敌人倒退 | 结算与移动两层钳制到 85%，包括符文增幅；检查原型和两分支 Lv50 解冻后的速度均正向 |
| 同帧升级/转职沿用旧属性缓存 | 购买及等级设置立即使该建筑缓存失效；检查新伤害/新分支标记即时可用 |
| 熔岩印记声称无限叠层，实际最多 5 层 | 文案明确现有五层与离开后衰减，未伪造无限效果 |

分支 mod 的语义为“覆盖”，需要移除的机制必须显式设为 0/false，不能用漏字段删除基础属性。毒伤保留无视护盾，并已接入抗性/易伤/按秒护甲；全部元素与共鸣附加、特殊敌人的综合反制仍需整体审计。

新 `building-art.js` 已替换旧建筑美术；48 外观、状态/等级结构、选中与范围的原生 Canvas 核验及截图见 BUILDING_ART.md。未验收：32 分支在所有阵容/难度中的成本收益与单边优势、全部共鸣/元素组合、真实目标优先级面板，以及物理设备性能。不能把视觉与基础机制回归当作完整进化验收。

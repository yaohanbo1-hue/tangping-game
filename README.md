## 📖 游戏简介

你是一个六年级学生，在梦里醒了过来。梦里有你的室友、有奇怪的建筑、还有从走廊深处不停爬向你的**梦魇**。

你的目标只有一个：**保护你的床铺**。

梦魇会被三扇铁门挡在走廊外侧。只要铁门破了，它们就会冲进房间，拆掉你辛苦发育的建筑，最后撕碎你的床——床铺一没，这局梦境就结束了。

所以你要做的事情很「躺平」：**慢慢攒钱 → 建矿机建发电机 → 铺炮塔 → 升级转职 → 一波一波把梦魇打回去。**

但这场梦并不简单。做到第 60 波才算通关；而在梦的深处，还有会说话的梦魇、会偷你金币的猫、假装游戏崩溃的「第四面墙」事件，以及藏在梦里的 20 块记忆碎片……

## ✨ 核心玩法

### 三种资源，一条命脉

| 资源 | 作用 | 怎么来 |
|------|------|--------|
| 💰 **金币** | 建造、升级建筑与铁门、升床、局内及跨局抽奖 | 金币矿机、床铺自动产出、击杀梦魇、梦境银行利息 |
| 🔮 **灵魂** | 点灵魂科技树、建筑「转职」、符文升级 | 击杀梦魇（精英/BOSS 掉更多）、成就奖励、剧情奖励 |
| ⚡ **电力** | 只用于 Lv.8 及以上的建筑升级；建筑运行与炮塔开火不耗电 | 发电机持续产出；局内摇奖可一次性补充 |

> ⚠️ 开局电量是 **0**。发电机能持续产电，适合尽早建造以支持高等级升级；不建发电机仍可正常建造和运行炮塔。

### 躺着发育，站着打怪

- **床铺**是你的核心，会自动产金币，还能升级（每级产币量翻倍），等级越高，你发育越快。
- 建筑从 **Lv.1 升到 Lv.50**，等级越高越强。
- 建筑升到 **Lv.6** 就可以**转职**（2 选 1 分支），转职后属性完全变样，比如机枪炮塔可以变成「加特林」（射速 ×2.6）或者「狙击塔」（伤害 ×3.4、射程 +70%）。
- 波与波之间有**备战时间**，你可以按 ⏩召唤 直接开下一波，剩余备战时间会折算成金币奖励。

### 六种伤害属性 + 抗性克制

| 属性 | 图标 | 特点 |
|------|------|------|
| 动能 | 🔫 | 基础物理伤害，对无甲梦魇效率最高 |
| 冰霜 | ❄️ | 附带减速，为其他炮塔创造输出窗口 |
| 能量 | 🔆 | 超远射程、高伤害、可穿透，专治重甲与 BOSS |
| 电磁 | ⚡ | 闪电在敌群中连锁跳跃，清小怪极快 |
| 火焰 | 🔥 | 近距离范围灼烧，堵门利器 |
| 剧毒 | 🧪 | 叠加毒层持续掉血，**无视护盾**直接侵蚀生命 |

每种梦魇都有自己的**抗性**和**弱点**——用对属性，伤害能翻好几倍；用错属性，可能只打出两三成伤害。

### 元素反应（6 种连锁效果）

不同属性的攻击命中同一只梦魇时会触发连锁反应：

| 反应 | 组合 | 效果 |
|------|------|------|
| 💨 蒸汽爆破 | 火焰 + 冰霜 | 瞬间汽化，额外造成一次伤害 |
| 💥 过载爆轰 | 电磁 + 火焰 | 引燃过载，小范围爆炸 |
| ☠️ 剧毒燃烧 | 剧毒 + 火焰 | 毒层翻倍并持续灼烧 |
| ⚡ 超导易伤 | 冰霜 + 电磁 | 躯体超导，受到的伤害提升 |
| 🧊 寒霜结晶 | 剧毒 + 冰霜 | 毒素结晶，定身梦魇 |
| 🧬 能量腐蚀 | 能量 + 剧毒 | 腐蚀躯体，永久降低全抗性 |

### 炮塔共鸣（相邻不同属性互相增幅）

相邻的**不同属性**炮塔会互相增幅，元素种类越多，加成越高：

| 共鸣 | 需要元素数 | 伤害加成 | 射速加成 |
|------|-----------|---------|---------|
| 🎵 双元素共鸣 | 2 | ×1.12 | ×1.00 |
| 🎶 三元素共鸣 | 3 | ×1.26 | ×1.10 |
| 🎼 四元素共鸣 | 4 | ×1.44 | ×1.18 |
| 🌈 全谱共鸣 | 5 | ×1.62 | ×1.26 |
| ✨ 万物共鸣 | 6 | ×1.85 | ×1.34 |

还有 6 种**特定组合**的隐藏加成，例如「火焰 + 动能 = 爆燃弹药（攻击附加灼烧）」、「冰霜 + 能量 = 碎冰弹（25% 概率定身）」、「能量 + 电磁 = 弧光场（额外弹射一个目标）」等等，全部靠自己排兵布阵试出来。

## 🌀 六大梦境创新系统

游戏在塔防基础上额外做了 6 套「梦境」系统，让每局都不只是打怪：

### 1. 🌿 梦境生态（DreamEcology）
梦魇之间会**互相影响**：治疗型梦魇会治疗同伴；召唤出来的小怪如果旁边有火焰型梦魇，会被点燃并爆炸；精英梦魇会给周围小弟上 buff；普通梦魇之间也会互相增幅。也就是说——**先杀谁，很重要。**

### 2. 🐾 中立生物（NeutralCreatures）
地图上会随机出现不攻击你的梦境生物：
- 🪲 **萤火虫**：无害，会发光
- 🧚 **梦境精灵**：保护它 3 波，会给你奖励
- 🐈‍⬛ **影子猫**：会**偷你的金币**！但它活够一定波数后也会给你稀有奖励

场上最多同时 3 只。

### 3. 🏠 NPC 驻守（NPCGuardians）
可以在走廊三条通道里招募 NPC 帮你防守，共 6 种：💊 梦境医师（治疗建筑）、⚔️ 梦境战士（提升炮塔伤害）、🧙 寒霜法师（减速敌人）、🧳 行商（每波产金币）、🛡️ 护盾守卫（给铁门加盾）、🔭 侦察兵（揭示隐身敌人）。

而且 NPC 之间有**羁绊和冲突**：医师 + 护盾守卫 = 「坚不可摧」（治疗、护盾双增强）；战士 + 侦察兵 = 「先发制人」；但行商 + 护盾守卫 = 「理念不合」（双方效果都下降）。所以**摆谁、摆哪里**也是策略。

### 4. 👁️ 第四面墙（FourthWall）
游戏会在特定波次「假装出问题」，让你真的怀疑是不是游戏坏了：
- 第 7 / 18 / 29 / 37 / 59 波：梦魇直接**跟你说话**
- 第 13 波：金币数字**上下颠倒**
- 第 26 波：画面**故障抖动**
- 第 30 / 49 波：**假崩溃**（弹出崩溃界面，3 秒后恢复）
- 第 22 / 43 波：存档「损坏」
- 第 55 波：屏幕颜色反转

### 5. 🌑 梦中梦（DeepDream）
在 **第 15 / 30 / 45 波**，你会被拖进更深层的梦境，每层持续 3 波，规则完全不同：

| 深层 | 变化 |
|------|------|
| 🌑 深渊第一层 | 更昏暗，敌人生命 ×1.5、速度 ×1.2，但火焰弱点 +30%，你的建筑伤害 -10% |
| 🕳️ 深渊第二层 | 时间变慢（×0.85），敌人生命 ×2.0、全抗性 +0.2，建筑射速 +15% |
| 👁️ 深渊第三层 | 梦中之梦，敌人生命 ×2.8、伤害 ×1.5，但你的建筑伤害 +20%、射速 +10% |

### 6. 🔊 梦境声音系统（DreamSound）
根据游戏状态动态切换环境音，进入深层梦境时会有低频嗡鸣和随机诡异音效，配合波次开始/结束、建筑开火、敌人死亡等音效反馈。

### 额外两个彩蛋系统

- 🕊️ **不战而胜（MercyPath）**：有 5 种梦魇其实是**可以被「理解」的**（迷失幽灵、慈悲灵、影卫、悔恨之魂、适应者）。满足条件时可以和它们对话，对话结束它们会自己离开，还会给你奖励——**不用打，也能过。**
- 📖 **梦境日记（DreamDiary）**：自动记录你每一局梦境里发生的事（剧情 / 战斗 / 发现 / 理解 / 碎片 / 驻守 / 深层 / 异常），并实时统计**梦境完成度**。

## 🔧 技术实现

- **纯前端单文件核心**：`tangping.html` 内嵌全部 HTML / CSS / JavaScript，无需服务器；WebAudio 音效直接合成。背景音乐为可选的外置 MP3，没放入音乐文件也能正常游玩
- **Canvas 2D 渲染**：1280×720 基准分辨率，自动等比缩放适配所有屏幕（手机、平板、电脑），不变形
- **事件驱动架构**：自研 `EventBus`（支持 `on` / `once` / `emit` / `clear`）解耦各大系统
- **毛玻璃 UI**：全界面使用 CSS `backdrop-filter` 实现 Glassmorphism 效果
- **梦境主页与剧情氛围**：主页整合难度、规则、开局道具、续玩记录、档案与快捷入口；剧情对话加入角色头像、波次标记和音乐压低效果
- **悬疑剧情与武器辨识度**：通过 03:07 闹钟、循环记忆与逐步揭露的线索串联委托；炮塔加入各自的炮管、核心、光效与专精外观
- **可选背景音乐**：支持主菜单、战斗和终局首领三种循环曲目，音乐与音效音量分别调节并记住设置；浏览器首次交互后启播
- **手机端适配（华为 / 安卓 / 苹果）**：`viewport-fit=cover` + `env(safe-area-inset-*)` 让刘海、灵动岛与底部横条不遮挡 HUD；尺寸优先取 `visualViewport`，地址栏收放不会把画布顶出屏幕；画布 `touch-action:none` 屏蔽误滚动与双击缩放，面板等可滚动区域单独放行纵向手势
- **触摸操作**：统一走 Pointer Events —— 轻触等同左键、拖动时实时跟随放置预览、长按 0.5 秒取消选择；触摸设备下面板滚动、剧情选项与底部操作栏按钮都加大了点击热区
- **横屏与全屏**：安卓侧可一键全屏并调用 `screen.orientation.lock('landscape')`；iPhone Safari 不支持横屏锁定，会退回「画面转向」方案（竖屏下把画面转 90° 占满屏幕），并给出「翻转方向」兜底，避免系统旋转锁定时画面上下颠倒
- **性能优化**：缓存星空与波次暗角、避免每帧创建渐变、生态计算降至 0.5 秒一次、粒子系统复用；触摸设备上把毛玻璃模糊半径从 24px 降到 12px 以减轻 GPU 压力
- **本地存档**：基于 `localStorage` 的进度保存（建筑、资源、波次、剧情选择、碎片收集）＋ 跨局保留的元数据（抽奖仓库、装备、最佳成绩）；载入时执行结构校验，不包含校验和或防篡改校验
- **零第三方依赖**：不使用任何框架或库，全部手写

如果想启用背景音乐，请按 [MUSIC_BRIEF.md](MUSIC_BRIEF.md) 用 MiniMax Music 3 生成三段循环曲，并按指定名称放入 `audio/`。运行 `tangping.html` 时，`audio/` 目录需与 HTML 放在同一文件夹；GitHub Pages 部署时也需一起发布。浏览器会在首次点击或按键后尝试播放。

### 修改源码后重新构建

源码是拆分的多个文件，项目版本保存在 `VERSION`。改完源码后运行构建脚本，重新生成 `index.html` 和 `tangping.html`：

```bash
node build.js
```

脚本会把 `shell.html` 与所有 `.js` 内联，输出可直接运行的 `tangping.html`。
